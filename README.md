# 通用剧情记忆（SillyTavern 扩展）

适用于**所有角色卡**，无任何卡片专属逻辑。要求 SillyTavern 1.12 及以上。当前版本 1.1.1。

## 功能
- **自动剧情总结**：每 N 条消息（默认 10）用当前 API 静默生成总结，追加到本聊天的长期记忆，并按设定深度/位置注入提示词。
- **关键词记忆**：总结时让模型输出 JSON，只**新增**尚未记录的设定/人物/地点/物品/事件；每次生成前扫描最近几条消息，命中关键词即注入对应条目。已有条目不会被自动改写。
- **记忆导入 / 导出**：把当前聊天的总结和关键词条目导出为 JSON，再导入到新角色卡、新聊天中接着用。支持覆盖或合并；手机或云端酒馆也可用「复制到剪贴板」和「从文本导入」。
- **设置面板**（扩展抽屉内）：开关、间隔、深度、位置、可编辑的总结提示词模板、查看/编辑/清空总结、编辑/删除/新增条目、「立即总结」「立即提取关键词」、调试模式，以及导出/导入记忆。

## 安装
1. 方式一：把整个 `st-memory` 文件夹放到 `SillyTavern/public/scripts/extensions/third-party/`，刷新页面。
2. 方式二：扩展面板 →「安装扩展 / Install extension」→ 填入本插件的 git 仓库地址。
3. 若已安装旧版：用本目录五个文件覆盖原扩展文件夹后，**刷新页面**（或在扩展面板中更新）。不要把新文件夹套在旧文件夹里面。

## 1.1.1 修复说明（关键词条目不再更新）
旧版常见原因：
- 模型回复不是严格 JSON（Markdown 代码块、中文键名、全角冒号、尾逗号、截断）时，解析失败，整段被当成总结，**条目数为 0**。
- 只要新条目和已有条目有任一关键词相同（例如又提到同一个角色名），就会把内容合并/覆盖进旧条目，**列表看起来一直不增加**。
- 提示词没有把已有关键词告诉模型，模型容易反复提取同一批人物。

1.1.1 起：解析更宽容；自动提取**只追加新条目、绝不改已有条目**；关键词重叠但内容确实是新的也会另开一条，仅跳过内容相同或高度相似的重复；提示词会带上已有关键词，并要求只提取新设定。若你还在用旧的默认模板，插件会自动换成新模板（自定义过的模板不会覆盖，但会在末尾补上已有关键词说明）。

## 导出 / 导入记忆
用于「新开一张角色卡 / 新开一个聊天，但接着用原来的记忆」。

1. 在**原来的聊天**里打开扩展设置「通用剧情记忆」，点「导出记忆」，会下载一个 JSON 文件（文件名含角色名和日期时间，例如 `记忆_角色名_2026-11-24_1653.json`）。下载不方便时，可点「复制到剪贴板」。
2. 打开新角色卡，并新开一个聊天。
3. 再打开本插件设置，点「导入记忆」选择刚才的文件；或把 JSON 粘贴到「或粘贴记忆 JSON 后导入」文本框，点「从文本导入」。
4. 先会确认是否导入到**当前聊天**。若当前聊天已有记忆，再问覆盖还是合并：
   - **覆盖**：用导入的总结和条目替换当前聊天的全部记忆。
   - **合并**：把导入的总结追加到现有总结末尾；条目按关键词去重后加入——若与已有条目有任一关键词重叠，则合并到该条目（关键词取并集；导入内容与已有不同则追加在后），否则新增一条。
5. 导入只写入当前聊天的记忆，不会改角色卡本身，也不会把旧聊天的消息进度（`lastIndex`）原样套过来。自动总结会从当前聊天已有消息之后继续，避免把新卡开场白再总结一遍，或因旧进度而长时间不总结。

导出文件是 UTF-8 的 JSON，主要字段为 `type`（固定 `st_memory`）、`summary`、`entries`（每条含 `keywords` 与 `content`）。也会附带 `version`、`exportedAt`、`character`、`lastIndex` 等元数据，导入时只使用总结和条目。

## 如何自测关键词提取
1. 覆盖文件并强制刷新酒馆页面，确认扩展版本为 1.1.1。
2. 打开一个已有剧情、且关键词列表里已有若干条目的聊天。
3. 点「立即提取关键词」（不改总结，只扫最近一段对话并追加新条目）。应弹出新增/跳过条数。列表只会变长或不变，已有条目的原文不应被改写。
4. 也可点「立即总结」：若有尚未总结的新消息，会追加总结并提取；若没有新消息，则改为按最近若干条只提取关键词，不会重复追加总结。
5. 若仍不加新条目：勾选「调试模式」再点一次「立即提取关键词」。打开浏览器控制台（F12），筛选 `[st-memory]`，查看 `raw response` 和 `parsed` 计数。

若修好后仍不更新，请把控制台里 `[st-memory] raw response` 和 `[st-memory] parsed` 两段日志发回来（可打码隐私）。

## 注意
- 总结和条目**按聊天保存**（存在聊天元数据里），换聊天/新开聊天各自独立；全局设置保存在 extension_settings。要把记忆带到新聊天，请用上面的导出/导入。
- 总结会消耗一次 API 调用。「立即提取关键词」也会。模型若没按 JSON 输出，插件会尽量解析；仍失败时总结可能仍会写入，但条目不会增加，并给出提示。
- 自动提取不会改已有条目；你仍可在面板里手动编辑或删除。
- 删除消息后不会自动回滚已有总结，可手动编辑。
- 导入前请确认已经打开目标聊天，否则会提示无法导入。
- 导入时的「合并」仍可能改写已有条目（按关键词合并），这只发生在你手动确认导入的时候，不会在自动提取时发生。
