# 通用剧情记忆（SillyTavern 扩展）

适用于**所有角色卡**，无任何卡片专属逻辑。要求 SillyTavern 1.12 及以上。当前版本 1.2.0。

## 功能
- **自动剧情总结**：每 N 条消息（默认 10）用当前 API 静默生成总结，追加到本聊天的长期记忆，并按设定深度/位置注入提示词。
- **关键词记忆**：总结或提取时，用**一次**请求同时做两件事——更新已有变化的旧词条，并新增尚未记录的设定/人物/地点/物品/事件。每次生成前扫描最近几条消息，命中关键词即注入对应条目。
- **单条更新**：每条词条旁有「更新此词条」，只针对该条目搜索相关对话并更新内容（可补充别名），消耗一次 API。
- **记忆导入 / 导出**：把当前聊天的总结和关键词条目导出为 JSON，再导入到新角色卡、新聊天中接着用。支持覆盖或合并；手机或云端酒馆也可用「复制到剪贴板」和「从文本导入」。
- **设置面板**（扩展抽屉内）：开关、间隔、回溯消息数、深度、位置、可编辑的总结模板和提取/更新模板、查看/编辑/清空总结、编辑/删除/新增/更新条目、「立即总结」「立即提取关键词」「撤销上次更改」、调试模式，以及导出/导入记忆。

## 安装
1. 方式一：把整个 `st-memory` 文件夹放到 `SillyTavern/public/scripts/extensions/third-party/`，刷新页面。
2. 方式二：扩展面板 →「安装扩展 / Install extension」→ 填入本插件的 git 仓库地址。
3. 若已安装旧版：用本目录五个文件覆盖原扩展文件夹后，**刷新页面**。不要把新文件夹套在旧文件夹里面。覆盖后版本应显示为 1.2.0。

## 1.2.0 更新了什么
旧版（1.1.1）按当时要求**不会改写已有词条内容**，所以「立即提取关键词」只能扫到新条目，旧条目的正文会停在第一次写下的状态。

1.2.0 起，在你明确操作或开启自动更新时，会把剧情进展写回旧词条：

- 每条词条的「保存 / 删除」旁新增 **「更新此词条」**：搜索含该条关键词的对话，并附带最近几条消息作上下文（优先使用该条上次更新之后的消息，总字数有上限）。一次请求，要求模型保留仍有效的旧信息、融入新进展。保存后可点 **「撤销上次更改」** 还原一次。出现新别名时会扩展关键词，不会删掉原来的词。
- **「立即提取关键词」** 改为一次请求同时：① 只返回有变化的旧词条更新（用 id 指定）；② 返回新条目。提示：「更新 X 条、新增 Y 条」。同样可撤销整批更改。
- 新增勾选 **「自动总结时也更新旧条目」**（默认开启）。自动总结和「立即总结」在提取时与上面同一套逻辑、仍只消耗一次 API。不想自动改旧词条时关掉即可；「立即提取关键词」和「更新此词条」始终会更新。
- 提取/更新提示词模板可在设置里编辑；也可分别恢复默认总结模板、默认提取模板。新增「提取/更新时最多回溯消息数」（默认 20）。
- 修正窄侧栏里按钮被竖排成逐字换行、以及「已提取」状态被截断的问题：按钮不折字，状态单独一行并可换行。

若你仍在用 1.0 / 1.1.1 的默认总结模板，插件会自动换成新模板（自定义过的不会覆盖，但会在末尾补上已有词条说明）。

## 按钮在哪
- 扩展设置抽屉「通用剧情记忆」里，总结编辑框上方：**立即总结**、**立即提取关键词**，需要时可出现 **撤销上次更改**。状态文字在按钮下一行。
- 「关键词记忆条目（当前聊天）」每一条：**保存**、**删除**、**更新此词条**。列表下方也有一个撤销按钮（有可撤销更改时才显示）。

## 如何自测
1. 覆盖五个文件并强制刷新，确认扩展版本为 1.2.0。按钮应横向显示，不再一字一行；点「立即提取关键词」后，状态应完整可见（例如「已提取 17:42 · 更新3条 · 新增1条」）。
2. 打开一个已有词条、且剧情已继续发展的聊天。点某条的「更新此词条」。成功后该条内容应写入新进展，并可点「撤销上次更改」还原。
3. 再点「立即提取关键词」。应弹出「更新 X 条、新增 Y 条」。旧词条若有新进展会被改写，新设定会追加。再点撤销，整批恢复。
4. 确认「自动总结时也更新旧条目」已勾选，聊满间隔条数（默认 10）后应自动总结并更新/新增。关掉该勾选后，自动总结只追加新条目、不改旧条目。
5. 若结果不对：勾选「调试模式」再操作一次，打开控制台（F12），筛选 `[st-memory]`，查看 prompt / raw response / parsed。

若仍异常，请把控制台里 `[st-memory] raw response` 和 `[st-memory] parsed` 两段发回来（可打码隐私）。

## 导出 / 导入记忆
用于「新开一张角色卡 / 新开一个聊天，但接着用原来的记忆」。

1. 在**原来的聊天**里打开扩展设置「通用剧情记忆」，点「导出记忆」，会下载一个 JSON 文件（文件名含角色名和日期时间）。下载不方便时，可点「复制到剪贴板」。
2. 打开新角色卡，并新开一个聊天。
3. 点「导入记忆」选择刚才的文件；或把 JSON 粘贴后点「从文本导入」。
4. 先会确认是否导入到**当前聊天**。若当前聊天已有记忆，再问覆盖还是合并。覆盖会替换全部总结和条目；合并会追加总结，条目按关键词去重后加入。
5. 导入只写入当前聊天的记忆，不会改角色卡本身，也不会把旧聊天的消息进度原样套过来。

## 注意
- 总结和条目**按聊天保存**（存在聊天元数据里），换聊天/新开聊天各自独立；全局设置保存在 extension_settings。切换聊天会清空「撤销」记录。
- 「立即总结 / 立即提取关键词 / 更新此词条 / 自动总结」每次各消耗一次 API 调用，不会为了更新旧词条再额外请求一次。
- 「撤销上次更改」只保留最近一次词条改动（含单条更新、批量提取、删除、导入），不能无限回溯。
- 删除消息后不会自动回滚已有总结，可手动编辑。
- 导入前请确认已经打开目标聊天。
