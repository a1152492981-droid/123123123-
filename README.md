# 通用剧情记忆（SillyTavern 扩展）

适用于**所有角色卡**，无任何卡片专属逻辑。要求 SillyTavern 1.12 及以上。当前版本 1.1.0。

## 功能
- **自动剧情总结**：每 N 条消息（默认 10）用当前 API 静默生成总结，追加到本聊天的长期记忆，并按设定深度/位置注入提示词。
- **关键词记忆**：总结时让模型输出 JSON，自动提取新设定/人物/事件为条目；每次生成前扫描最近几条消息，命中关键词即注入对应条目。
- **记忆导入 / 导出**：把当前聊天的总结和关键词条目导出为 JSON，再导入到新角色卡、新聊天中接着用。支持覆盖或合并；手机或云端酒馆也可用「复制到剪贴板」和「从文本导入」。
- **设置面板**（扩展抽屉内）：开关、间隔、深度、位置、可编辑的总结提示词模板、查看/编辑/清空总结、编辑/删除/新增条目、"立即总结"按钮，以及导出/导入记忆。

## 安装
1. 方式一：把整个 `st-memory` 文件夹放到 `SillyTavern/public/scripts/extensions/third-party/`，刷新页面。
2. 方式二：扩展面板 →「安装扩展 / Install extension」→ 填入本插件的 git 仓库地址。
3. 若已安装旧版：用本目录五个文件覆盖原扩展文件夹后，刷新页面（或在扩展面板中更新）。

## 导出 / 导入记忆
用于「新开一张角色卡 / 新开一个聊天，但接着用原来的记忆」。

1. 在**原来的聊天**里打开扩展设置「通用剧情记忆」，点「导出记忆」，会下载一个 JSON 文件（文件名含角色名和日期时间，例如 `记忆_角色名_2026-11-24_1653.json`）。下载不方便时，可点「复制到剪贴板」。
2. 打开新角色卡，并新开一个聊天。
3. 再打开本插件设置，点「导入记忆」选择刚才的文件；或把 JSON 粘贴到「或粘贴记忆 JSON 后导入」文本框，点「从文本导入」。
4. 先会确认是否导入到**当前聊天**。若当前聊天已有记忆，再问覆盖还是合并：
   - **覆盖**：用导入的总结和条目替换当前聊天的全部记忆。
   - **合并**：把导入的总结追加到现有总结末尾；条目按关键词去重后加入——若与已有条目有任一关键词重叠，则合并到该条目（关键词取并集；导入内容与已有不同则追加在后），否则新增一条。
5. 导入只写入当前聊天的记忆，不会改角色卡本身，也不会把旧聊天的消息进度（`lastIndex`）原样套过来。自动总结会从当前聊天已有消息之后继续，避免把新卡开场白再总结一遍，或因旧进度而长时间不总结。

导出文件是 UTF-8 的 JSON，主要字段为 `type`（固定 `st_memory`）、`summary`、`entries`（每条含 `keywords` 与 `content`）。也会附带 `version`、`exportedAt`、`character`、`lastIndex` 等元数据，导入时只使用总结和条目。

## 注意
- 总结和条目**按聊天保存**（存在聊天元数据里），换聊天/新开聊天各自独立；全局设置保存在 extension_settings。要把记忆带到新聊天，请用上面的导出/导入。
- 总结会消耗一次 API 调用。模型若没按 JSON 输出，整段回复会被当作总结，不提取条目。
- 删除消息后不会自动回滚已有总结，可手动编辑。
- 导入前请确认已经打开目标聊天，否则会提示无法导入。
